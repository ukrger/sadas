# Train Summer — Godot 0.1

**Самостоятельный запускаемый проект для Godot 4.6.3 Standard, GDScript, Forward+.** Unity, URP, .NET, Blender и дополнительные плагины для запуска не нужны. Это первая игровая версия переноса, не готовая коммерческая игра и не финальная графика уровня UE4.

## Самый простой запуск
1. Установи **Godot 4.6.3 Standard** с официального сайта godotengine.org. Выбирай обычную версию; .NET не требуется.
2. Распакуй архив в отдельную папку. Не запускай файлы прямо из ZIP.
3. Открой Godot → **Import / Импорт** → выбери **project.godot** внутри распакованной папки → **Import & Edit / Импортировать и редактировать**.
4. Дождись первого импорта GLB, текстур и шейдеров. Он может занять некоторое время.
5. Нажми **F5**. В меню нажми **«Начать маршрут заново · короткий»**. Сцена уже настроена: создавать объекты и выбирать главную сцену вручную не нужно.

В главном меню есть отдельная кнопка длинного маршрута. Переключение перезапускает сцену; ручной слот и автосохранение короткого/длинного профиля раздельные. На коротком маршруте первая остановка примерно через 25 секунд; на длинном интервалы поездки примерно 6–7 минут. Плановое ожидание — 180 игровых секунд.

Если видеокарта/драйвер не поддерживает Vulkan, обнови драйвер либо выбери **Compatibility** вместо Forward+ в правом верхнем углу редактора. Совместимый режим проще по свету: высокие SSAO/volumetric fog рассчитаны на Forward+. Начни с пресета «Среднее». При проблемах пришли первую красную ошибку из нижней панели Debugger/Output, не только пустой игровой экран.

## Игровая цель
Собери **четыре радиомодуля** из раций в станционных домах и доведи поезд до конца пути. Модуль каждой станции нужно забрать перед отправлением. Пройди доски топором, пополняй топливо, ремонтируй состав, следи за здоровьем, едой и водой. Рюкзак открывается без остановки времени.

После истечения таймера поезд ждёт, пока игрок вернётся на борт, получит модуль и устранит нехватку топлива/поломку. Можно отправиться раньше из передней кабины. Автоотправление отключается в настройках и сохраняется со слотом.

## Управление
| Клавиша | Действие |
|---|---|
| WASD / мышь / Space | Ходьба / взгляд / прыжок |
| E | Взаимодействовать: предмет, рация, верстак, передний пульт |
| Tab | Открыть / закрыть 3D-рюкзак |
| 1 / 2 / 3 / 4 | Топор / пистолет / дробовик / автомат |
| ЛКМ / удержание ПКМ | Атака / прицеливание |
| R / F | Зарядка / фонарик |
| Esc | Пауза / возврат из настроек |
| F5 / F9 | Сохранить / загрузить |
| F2 | Показать / скрыть FPS |

Оружие находится в вагоне: топор/пистолет/патроны на заднем верстаке, дробовик и автомат возле левой стены за сиденьями. Выход — справа в задней части вагона. На платформе есть ступени к земле. В домах — топливо, припасы, патроны и рация. Для подбора наведи камеру и нажми E.

В рюкзаке клик по 3D-предмету использует припас либо выбирает оружие. Для расходников есть также кнопки. Ремнабор = 3 детали + 1 ткань; аптечка = 1 деталь + 2 ткани. Ремонт требует остановленного поезда и игрока на борту, даёт до +25 состояния. Верстак использует готовый набор либо создаёт его при наличии материалов. Вода даёт до +45, еда +35, аптечка +35 здоровья; при полном показателе предмет не тратится.

При смерти доступны загрузка и новый маршрут. В конце пути с четырьмя модулями появляется экран завершения. Это короткая игровая цель прототипа, не полноценная сюжетная кампания.

## Что перенесено
- Кривой маршрут, разгон/тормоз/плановые остановки, топливо/износ/ремонт, короткий и длинный профиль.
- FPS CharacterBody3D: ходьба, ступени, прыжок с наследованием скорости состава, урон от падения. На прикреплённой палубе используется локальная опора с горизонтальным swept collision, на земле/в прыжке — move_and_slide. Такой режим устранил проверенное сползание персонажа при движении поезда.
- Лут, ограниченные стеки, потребности, крафт, физическое 3D-полотно. Рюкзак отображается собственным прозрачным SubViewport/World3D, чтобы сиденья/стены вагона не закрывали предметы; основной мир продолжает работать. Перетаскивания и скелетных анимаций рук пока нет.
- Топор и три огнестрельных оружия: пистолет 12, дробовик 5/8 дробин и поштучная зарядка, автомат 30 с удержанием огня. Отдельные резервы, баллистические сегменты с гравитацией, пул 64 трассеров, препятствия блокируют попадания.
- ADS по ПКМ: плавная поза по точке прицела, FOV 75 → 58, меньше разброс/покачивание, чувствительность/скорость ходьбы, настоящая отдача взгляда. Рюкзак/пауза/смена/загрузка сбрасывают ADS; зарядка выводит из него. Оптики и пристрелки нет.
- Два варианта врага, NavigationAgent3D и станционный NavMesh, реакция на видимость/шум/фонарь, атака с проверкой прямой видимости. Навигация запекается при старте; после разрушения досок перепекается станция.
- Стартовое меню, RU/EN, пауза, настройки Low/Medium/High, FPS/V-Sync/лимит кадров, чувствительность, полный экран. Все графические тонкие настройки прежней Unity-версии ещё не перенесены отдельными ползунками.
- Сохранения с SHA-256 и резервной копией, отдельные ручной/авто слоты, состояние лута/досок/врагов/оружия/состава/модулей/таймера. Загруженные данные проверяются до изменения сцены.

## Графика и оптимизация
- **23 собственные модели GLB**, конвертированные из исходных BLEND; три исходных LOD. Руки статические, враги с generic-скелетом и простыми Idle/Walk. Blender не нужен для импорта GLB.
- 21 собственная процедурная карта. Назначаются albedo/normal/metallic; roughness задаётся материалами. Это базовые поверхности, не финальные фотосканированные текстуры.
- Тёплый дневной свет, лёгкая дымка, ясное небо с редкими облаками, закат, луна/звёзды и холодная ночь. Дождя/бури нет. Сутки — примерно 20 минут.
- Forward+ с ACES. High включает SSAO и нативный volumetric fog, Medium их отключает; SDFGI не включён. Reflection Probes/запечённый свет и художественная доводка остаются следующими задачами.
- **10 переиспользуемых чанков** по 80 м: 7 у поезда плюс до 3 у пешего игрока. Не бесконечная карта во всех направлениях; вне поперечного коридора нет полноценной физической земли. Дальний фон — декоративная плоскость без коллизий.
- Рельсы/шпалы объединены в 2 меша на чанк. Земля — процедурный меш с физической поверхностью. Перестановка обновляет меши и коллизии; native resource allocations/пики требуют профилирования.
- MultiMesh деревьев/травы, LOD по диапазонам batch instances, shader wind, frustum culling, дальние растения без теней. По 64 дерева и до 1400 травяных пятен на чанк; видимая трава ограничивается пресетом. Это coarse batch LOD, не индивидуальный LOD каждого дерева. Импорт GLB также включает автоматическую генерацию mesh LOD.
- У станций консервативные occluders в непрозрачных стенах, с сохранением окон/дверей. Дальние станции отключают AI/коллизии/NavMesh; **ассеты остаются в памяти**, additive scene/asset unload не реализован. Редкие руины вне станций декоративные, без отдельного лута.
- Синтезированные временные звуки поезда/воздуха/шагов/выстрела без чужих записей. Аудио выключается в headless-тестах.

**Цель — 60 FPS в 1080p на выбранном среднем ПК, не доказанный результат.** В этой среде выполнен настоящий Forward+ Vulkan-рендер через программный Mesa llvmpipe, а не игровую GPU. Его скорость не характеризует производительность пользователя. Финальной картинки уровня хороших UE4-проектов ещё нет; она требует дальнейших моделей, текстур, анимаций, освещения и профилирования.

## Сохранения
Godot: Project → Open User Data Folder. Там save_short.json / autosave_short.json либо save_long.json / autosave_long.json, предыдущие .bak и settings.json. F9 пробует ручной слот, при его отсутствии — автоматический; повреждённый основной файл пробует резервную копию. Пули, зарядка и открытый рюкзак не сохраняются.

**Unity-сохранения с этим переносом несовместимы.** Новый маршрут сбрасывает сессию, но не удаляет файлы сохранения. Не меняй ID предметов/врагов вручную, если нужна совместимость.

## Проверка и сборка
Выполненные проверки и ограничения — TEST_REPORT.md. Команды из папки проекта:

    godot --headless --editor --path . --import
    godot --headless --path . --fixed-fps 60 --script res://tests/run_checks.gd
    godot --path .
    godot --path . -- --long-route

В Godot Project → Export подготовлен Windows Desktop preset. Установи Export Templates для **той же версии** Godot, создай папку build, затем Export Project. Готовая Windows x64 сборка: https://raw.githubusercontent.com/ukrger/sadas/main/Downloads/TrainSummer_Windows_0.1.zip . Распакуйте и запустите TrainSummer.exe; редактор не нужен. Встроенный пакет прошёл 79 проверок на Linux. Нативный запуск в Windows здесь не проверен.

## Исходники моделей
GLB включены полностью. Исходные BLEND/генераторы сохранены в Unity-репозитории: https://github.com/ukrger/sadas/tree/main/Tools/Blender . Повторный экспорт:

    blender -b --python tools/export_models.py -- --source /path/to/Tools/Blender/Source --output /path/to/this/project/assets/models

Скрипт открывает исходные .blend; запускай в background/отдельном Blender. Аудио повторно генерируется командой python tools/synthesize_audio.py.
