# Этапы и честные критерии готовности

Работа организована крупными связанными обновлениями, без запроса разрешения после каждого модуля. Статус «исходники подготовлены» не равен «проверено в Unity». Сессия не выполняется в фоне после ответа.

| Этап | Текущий результат | Что ещё подтверждать |
|---|---|---|
| Архитектура, URP, маршрут, движущийся поезд | Подготовлены генераторы, контроллеры, станции и 10 pooled чанков | Unity-компиляция, переходы вагон/земля, полный маршрут |
| Лут, потребности, крафт, физический рюкзак | Подготовлены фиксированные 3D-слоты и транзакции; ядро исполнялось в .NET | Камеры/коллизии/интеграция, UX, анимации рук и перетаскивание |
| Бой и восприятие AI | Пистолет, дробовик, автомат, топор, gravity projectiles, NavMesh/шум/фонарь; zombie/mutant variants | Unity PlayMode, стрельба/дробь/стены/AI, баланс, финальная анимация |
| Прицеливание | Точные sight markers, плавный ADS, FOV/чувствительность/ходьба/разброс/отдача | Unity play при разных FPS/aspect ratio; оптика/пристрелка не реализованы |
| Цель и завершение | 4 радиомодуля, timer/manual departure, start/death/victory UI, schema-3 saves/migrations | Реальное полное прохождение, все переходы сохранений и меню |
| Ясное лето/ночь | Свои небо/луна/звёзды, PBR-карты, ветер и screen-space sun shafts | HLSL, night lighting, reflection probes, финальная графика и звуки |
| Производительность | Instancing/LOD/pooling/frustum, station activation, occlusion bake command | Профилирование на целевом ПК; additive asset unload и floating origin пока нет |
| Самостоятельные модели | Все прежние FBX плюс 6 новых моделей 0.9, source .blend/генераторы/LOD/рендеры | Финальная геометрия/UV/текстуры/skin weights/анимации, Unity-импорт |
| Проверка/сборка | 93 независимые проверки, Blender validators, Unity tests + batch/build tools подготовлены | Компиляция/тесты/Development Build в установленной Unity; EXE не собран |

Следующий блок начинается с Unity, а не с объявления игры завершённой. Нужен доступный редактор Unity 2022.3 LTS и его результаты: импорт, EditMode/PlayMode, создание сцен, Windows Development Build и профиль CPU/GPU. Здесь редактора нет; эти проверки невозможно заменить рендерами Blender, tree-sitter или независимым .NET.

После прохождения этих ворот: исправления по движку, настоящий performance pass, анимации и освещение, разнообразие станций/задач, звук/баланс, тестирование RU/EN/UI на разных разрешениях, длительный прогон сохранений и сборки. Число версии 1.0 использовать только после подтверждённой приёмки, не по наличию файлов.
