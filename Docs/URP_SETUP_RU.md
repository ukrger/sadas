# Базовая летняя картинка URP 14

Референс Metro Exodus задаёт настроение, а не обещанное совпадение качества. Фотореализм требует детальных ассетов, грамотного света, материалов, анимаций и проверки в реальном кадре. Текущие модели и карты — техническая художественная база.

| Параметр | Стартовая настройка среднего ПК |
|---|---|
| Renderer | Universal Forward; SRP Batcher включён |
| Rendering | Linear color space, HDR, Render Scale 1.0 |
| AA | MSAA 2x; сравнить 4x на сильной GPU |
| Main Light | Directional, shadows 2048, distance 70–80 м, 2 cascades |
| Additional Lights | Per Vertex либо ограниченное Per Pixel; не давать тени каждому фонарику |
| Soft Shadows | Medium; проверить их цену отдельно |
| Camera | Near .05, Far 300, FOV 75 / ADS 58 |
| Post | ACES, Bloom .15 / threshold 1.1, без motion blur и постоянного DOF |
| Environment | Flat ambient из цикла, лёгкая ясная дымка; не использовать серый пасмурный grading |
| Texture | Mipmaps, repeat для тайлов, anisotropic 4–8, нормальные карты как Normal Map |
| Standalone instancing | Graphics → Shader Stripping → Instancing Variants: Keep All для первого прогона |

Это стартовые значения, не измеренный пресет производительности. Генератор создаёт свои URP shadow/Forward renderer assets на базе вашего; original URP Asset остаётся исходным. Собственный SummerSky назначается в сцене, а в Play используется его временная копия. SettingsService выбирает временную копию одного из generated-профилей. Для своей сцены копируйте все связанные renderer assets/features вместе.

SunShaftFeature строит маску неба по глубине, размывает к солнцу и добавляет тёплый свет. Это экранный эффект: за пределами экрана/при полной окклюзии лучи ограничены, возможны ореолы у контрастных границ. Нет полноценного объёмного освещения/рассеяния в пространстве. Параметр intensity в generated JourneyRenderer_*.asset можно уменьшить или выключить. В Low эффект не исполняется, поскольку post-processing выключен.

Летний цикл: солнечный день, тёплый горизонт у рассвета/заката, синеватая ясная ночь с луной и звёздами. Погода не меняется на дождь или бурю. Облака редкие и неподвижные. Отражения/запечённое GI не пересчитываются каждый кадр; финальная работа с Reflection Probes и освещением интерьеров остаётся отдельной проверкой.

## Бюджеты окружения
- Растения: общие меши/материалы, frustum culling, программный LOD; дальний LOD без отбрасывания теней. Фактические instanced draws проверить в Frame Debugger.
- Фиксированные 10 чанков: 7 возле поезда, до 3 вокруг игрока. Путь объединён в 2 render meshes + mesh collider на чанк.
- Станции: включение возле поезда ИЛИ игрока, гистерезис, отключение AI/NavMesh с дальним корнем. Ассеты остаются в памяти.
- Occlusion: bake только устойчивой станционной геометрии, исключая предметы/врагов и dynamic поезд. Проверять ошибки bake и popping. Бэйк не заменяет culling explicit instancing.
- Статические PBR-карты запечены один раз, не генерируются заново каждый кадр. Всего 21 PNG по 256² на семь поверхностей, переиспользуемых материалами. FoliageWind использует vertex colors, а не эти texture normal maps.
- Не включать realtime GI, SSAO высокой точности, тени всех локальных ламп и дальнюю густую траву одновременно без измерения GPU. Любые более дорогие эффекты включать после базового профиля.

Для оптимизации используйте конкретное место/длительность прохода и одинаковые условия, отдельно сравнивая CPU/GPU. После фиксации art-набора можно менять размеры карт, атласы, LOD-пороги, кеширование физического пути и настоящую выгрузку станций. Floating origin не реализован: текущий маршрут ограничен примерно 16 км.
