# Летний маршрут — Unity-прототип 0.1

Это исходники первого технического этапа, не готовая игра и не фотореалистичный набор моделей.

## Запуск
1. Создать новый проект **Unity 2022.3 LTS → 3D (URP)**. Требуется URP 14.
2. Установить **Input System** через Package Manager.
3. Project Settings → Player → Active Input Handling → **Input System Package (New)** или **Both**; перезапустить редактор по запросу.
4. Скопировать содержимое папки `Assets` пакета в `Assets` своего проекта. В `Assets/Models` уже есть сгенерированная канистра FBX; сцена пока использует ее простой коллизионный аналог.
5. Дождаться компиляции. Выбрать **Train Summer → Create Prototype Scene**. Генератор предложит сохранить открытую сцену.
6. Открыть созданную `Assets/TrainSummer/Generated/Prototype.unity`, нажать Play.

Генератор не меняет URP Asset существующего проекта. Нужен действующий URP-шаблон. Generated — папка генерируемых материалов и сцены; не храните в ней ручные правки при повторном запуске.

## Управление
WASD — ходьба, мышь — обзор, Space — прыжок, Esc — освободить/захватить курсор.
E у переднего пульта — тормозить/продолжить движение; E при наведении на канистру — собрать топливо.
F1 — RU/EN, F2 — счетчик FPS. Esc освобождает курсор, но не ставит игру на паузу.

## Проверочный маршрут
Поезд начинает движение автоматически. До первой остановки около 25 секунд (укороченный тест вместо 5–10 минут).
Станция расположена на отметке 160 м. После автоматической остановки идите к задней части вагона и выйдите через проем справа. На платформе — оранжевая канистра; подойдите, наведитесь и нажмите E. Вернитесь по ступеням, подойдите к переднему пульту и нажмите E. Следующих остановок в этом этапе нет.

## Реализовано
- Кинематическое движение по прямому пути, разгон, торможение, расход/пополнение топлива.
- Плановая остановка, ручное отправление с проверкой нахождения игрока на поезде.
- Контроллер первого лица с переносом опорой без parenting.
- Процедурная серая модель вагона, ступени, платформа, укрытие, канистра.
- Ограниченное окно чанков: земля, рельсы, шпалы, простые деревья.
- Простой солнечный цикл, URP Volume, минимальный двуязычный интерфейс.
- Отдельный Blender-генератор канистры с FBX-экспортом.

## Ограничения и следующий этап
Unity отсутствует в среде создания пакета: C# и сцена НЕ были скомпилированы или запущены в Unity. Проверка физики, изображения и FPS обязательна в редакторе и Windows-сборке.
Перенос платформой — начальный вариант: скорость платформы при прыжке не наследуется; повороты и длинный маршрут пока отсутствуют. Мировой origin не смещается, сохранений нет.
Стример создает/удаляет примитивы синхронно; это ограничивает число объектов, но НЕ является готовым pooling или additive streaming. Возможны пики CPU на границах чанков.
Деревья — примитивы без LOD и специальных шейдеров; GPU instancing материалов включен, но фактические batching/draw calls не проверены. Солнце и ambient меняются, полноценной луны, звезд и корректных ночных отражений пока нет. UI на OnGUI временный; Unity Localization и полноценные настройки еще не подключены.

Следующий этап: проверить переходы вагон/платформа; затем добавить кривую маршрута, перенос скорости при прыжке, pooling/асинхронную загрузку, сохранение состояния чанков. Оружие, враги, физический рюкзак и фотореалистичные ассеты выполняются последующими модулями.

## Проверка в Unity
- В Console нет ошибок после импорта и запуска.
- При ходьбе в поезде игрок не отстает и не проходит сквозь пол.
- На станции поезд останавливается без перелета.
- Выход/возвращение по ступеням работают; E собирает канистру один раз.
- До возвращения игрока отправление не происходит; у пульта после возвращения поезд отправляется.
- Esc отключает движение и взаимодействие; F1/F2 работают.
- За 10 минут количество Route_* остается ограниченным (7 после завершения Destroy), память не растет постоянно.
- Профилировать standalone Development Build на целевом ПК; не считать FPS редактора гарантией.

## Проверки пакета
- Все 7 C# файлов прошли синтаксический разбор tree-sitter C# без ошибок. Это не проверяет Unity API и не заменяет компиляцию.
- Генератор канистры выполнен в Blender 4.3.2: экспортирован бинарный FBX и сохранен исходный .blend.
- Математическая модель торможения проверена отдельно при 20/30/60/144 FPS: остановка на 160 м. Это не проверка Unity-физики.
- Готовый FBX: Assets/Models/FuelCan.fbx. Исходник: Tools/Blender/Source/FuelCan.blend. Импорт материалов нужно проверить и настроить под URP; Blender-материал не гарантирует автоматический перенос.
