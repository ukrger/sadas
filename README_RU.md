# Train Summer — технический прототип 0.7

Пакет исходников и собственных моделей для **Unity 2022.3 LTS / URP 14**. Это не готовая игра и не EXE. В 0.7 добавлены 3D-полотно рюкзака, базовый крафт, сытость/вода и новая тройка моделей. Системы боя, сохранений и настроек из 0.6 сохранены.

## Запуск и обновление
1. Создайте проект Unity 2022.3 LTS из шаблона **3D (URP)**.
2. Установите **Input System** в Package Manager. Player → Active Input Handling → Input System Package (New) либо Both; перезапустите редактор по запросу.
3. Скопируйте содержимое `Assets` из пакета в `Assets` своего проекта с заменой одноименных исходников. Дождитесь импорта FBX и компиляции.
4. Выберите **Train Summer → Create Prototype Scene** для короткого теста или **Create Long Route Scene** для длинного маршрута.
5. Генератор создаст сцену, URP-материалы, LODGroup, NavMesh каждой станции, контроллер анимации врага и игровые компоненты. Затем нажмите Play.

Для врагов используется встроенный UnityEngine.AI/NavMeshBuilder, отдельный пакет AI Navigation не требуется. Для приложенных Unity-тестов нужен Unity Test Framework. Blender требуется только для повторной генерации моделей, а не для импорта FBX.

**После обновления с 0.5 сцену обязательно пересоздать.** Старые сцены сами не получают ссылки на оружие, врагов, сохранения и настройки. Перед генерацией сохраните ручные изменения в другой сцене: Generated/Prototype.unity либо Generated/Prototype_Long.unity будет перезаписана. Файлы Generated принадлежат генератору; не используйте их как единственный экземпляр ручной работы.

Первое создание навигационных данных и прогрев семи участков синхронные. Время генерации и стартовые пики нужно проверить в Unity. Состояние URP Asset существующего проекта генератор не изменяет. Во время игры настройки используют временную копию URP Asset; при выходе восстанавливаются прежние ссылки и глобальные параметры качества.

## Новое в 0.7
- **Tab или E на рюкзаке:** камера опускается, открывается 3D-полотно с моделями собранных предметов. Нажатие на воду, еду и аптечку использует предмет; оружие выбирается для экипировки после закрытия рюкзака. Детали, ткань и патроны показывают количество.
- Предметы размещены в фиксированных категориях. Количество представлено одним визуальным экземпляром со счетчиком; пустые категории скрываются. Рюкзак открывается без паузы, но ходьба, обзор и атака блокируются. Перенос игрока движущимся поездом продолжается.
- **Крафт в рюкзаке:** ремонтный набор = 3 детали + 1 ткань; аптечка = 1 деталь + 2 ткани. Это условные игровые рецепты. При нехватке ресурсов или полном выходном стеке материалы не тратятся.
- Набор используется внутри остановленного поезда и восстанавливает до 25 пунктов состояния. Верстак сначала использует готовый набор, а при его отсутствии выполняет прежний ремонт из деталей/ткани.
- **Сытость и вода:** старт 90/85, расход 0,025/0,045 пункта в игровую секунду. Консервы дают до +35 сытости, бутылка до +45 воды. При пустом любом показателе снимается 1,5 здоровья/с; два пустых показателя не удваивают урон. В паузе показатели не падают. После временного respawn они восстанавливаются до 100.
- Новые припасы лежат на полу справа за сиденьями вагона и в задней части каждого станционного дома. Подбор — E. Новые предметы и показатели входят в сохранение.
- Схема сохранения повышена до 2. Для стандартной сцены 0.6 добавлена миграция: прежний лут/враги сохраняются, новые припасы получают исходное состояние, сытость и вода становятся 100. Перенос измененной вручную сцены не гарантируется.
- Исправлена ошибка API в прежних настройках теней: URP 14 не предоставляет публичного setter для mainLightShadowmapResolution. Генератор теперь создает три URP-профиля теней через Editor; runtime переключает их копии. У overlay-камеры используется штатная очистка глубины без присвоения read-only свойства.

### Как устроен 3D-рюкзак
Полотно — процедурный меш с небольшими складками. Предметы используют реальные FBX и LOD0; детали и ткань пока представлены простыми мешами. Отдельная overlay-камера URP отображает слой 9 поверх мира, чтобы геометрия вагона не перекрывала предметы. Основная камера смотрит вниз. Коллайдеры выбора — триггеры и не должны толкать игрока. Это 3D-представление с фиксированными слотами, а не свободное перетаскивание вещей, симуляция ткани или анимация рук.

Для рюкзака рекомендуется стандартный **URP Forward Renderer** с поддержкой camera stacking. При несовместимом renderer используется менее надежный вариант обычного отображения в мире; полотно может перекрываться окружением. Слой 9 зарезервирован для инвентаря. Overlay работает только при открытом рюкзаке; стоимость нужно измерить в Unity.

`Previews/InventoryClothLayout.png` — Blender-превью раскладки из экспортированных мешей, **не скриншот Unity**. Кнопки крафта, счетчики и курсор в нем не показаны.

## Управление
| Клавиша | Действие |
|---|---|
| WASD / мышь / Space | Ходьба / обзор / прыжок |
| E | Подбор, ящики, верстак; у переднего пульта — тормоз/отправление |
| ЛКМ | Атака выбранным оружием |
| 1 / 2 | Топор / пистолет; повторное нажатие убирает выбранное оружие |
| R | Перезарядка пистолета; после гибели — возврат в поезд |
| H | Лечение аптечкой при закрытом рюкзаке |
| F | Фонарик |
| Tab | 3D-рюкзак: мышь выбирает/использует предметы, кнопки внизу создают предметы |
| Esc | Пауза и настройки; повторное нажатие продолжает игру |
| F1 / F2 / F3 | RU/EN / FPS / справка |
| F5 / F9 | Ручное сохранение / загрузка |

При открытом меню паузы мир, AI и пули останавливаются. Tab не ставит мир на паузу; обзор, ходьба, атака и взаимодействие с миром при открытом рюкзаке отключены. Нажатие Esc поверх рюкзака ставит мир на паузу; после продолжения рюкзак остается открытым. Настройки языка/FPS через F1/F2 действуют сразу; для записи настроек на диск используйте меню «Применить и сохранить».

## Игровой цикл
- Поезд трогается автоматически. На маршруте четыре последовательные станции; отправление со станции ручное у переднего пульта после возвращения игрока.
- Возьмите топор и пистолет у верстака сзади слева в вагоне. Рядом есть патроны. Рюкзак стоит за сиденьями и открывает то же 3D-полотно, что Tab.
- На станции выйдите через правый задний проем по ступеням. Дом находится за платформой; на входе доски, которые разбиваются тремя ударами топора.
- Внутри дома: топливо на столе, ящик деталей/ткани, аптечка на полке, патроны. В окрестностях два мутанта. Шум выстрелов и шагов привлекает их внимание.
- Вернитесь в вагон, отремонтируйте поезд на остановке, запустите отправление из кабины.

### Поезд и мир
RoutePath хранит таблицу длины дуги: скорость задается в метрах вдоль плавной горизонтальной кривой. Рельсы и шпалы следуют тому же пути. Семь участков мира создаются при старте и затем переиспользуются; переходы между чанками не создают и не уничтожают их GameObject. Перенастройка большого количества коллайдеров все еще может вызывать пики CPU.

Короткий маршрут: остановки 160 / 640 / 1200 / 1800 м, конец около 2214 м. Первый перегон около 25 секунд, следующие примерно 65–80 секунд. Длинный маршрут: остановки 2800 / 6000 / 9200 / 12400 м, конец около 15,7 км; перегоны примерно 6–7 минут при 8 м/с. Эти длительности рассчитаны численно, без ручного торможения.

Топливо расходуется отдельно от состояния поезда. Начальное состояние 60%, износ 0,006 пункта на метр. Ящик выдает 4 детали и 2 ткани один раз. Ремонт стоит 3 детали + 1 ткань и восстанавливает до 25 пунктов; при движении, полном состоянии или недостатке ресурсов списания нет. При поломке или пустом баке тормоз фиксируется — после обслуживания его нужно снять у пульта.

### Оружие и враг
Пистолет: магазин 12, урон 30, интервал 0,22 с, перезарядка 1,4 с, начальная скорость пули 280 м/с. Коробка дает 24 патрона в резерв. При перезарядке патроны переносятся из резерва, а не создаются. Переключение оружия отменяет незавершенную перезарядку без списания.

Пули симулируются с гравитацией и проверкой пройденного отрезка, переиспользуют 32 трассера. Первое препятствие останавливает пулю. У пистолета простая процедурная отдача модели и синтезированный звук — не запись реального оружия. Топор: 25 урона, дальность 1,8 м, задержка 0,7 с; один удар наносит урон один раз, ближайшее препятствие закрывает цель.

Мутант: 100 здоровья, NavMeshAgent, патруль, проверка услышанной позиции, преследование, атака с проверкой видимости. Обзор ограничен углом и препятствиями; ночью дальность обычного зрения уменьшается. Фонарик помогает заметить игрока при попадании луча в противника. Выстрелы и шаги передают AI события звука; отдельной озвучки шагов и мутанта пока нет. Атака снимает 10 здоровья с интервалом 1,3 с. Враг пока не умеет садиться в поезд.

NavMesh генерируется для каждой станции из статических коллайдеров и дополнительной плоской поверхности. Доски используют NavMeshObstacle с carving: после разрушения проход должен открываться. Деревья, перемещаемые пулом, не включены в эту навигацию; возможное прохождение врага через отдельный ствол остается ограничением. Участки карты плоские.

Модель мутанта имеет Generic-скелет из 11 костей и анимации Idle/Walk; движения сегментов простые, без финального художественного рига. Отдельной анимации атаки, ragdoll и озвучки пока нет.

### Здоровье
Игрок начинает с 70/100 для проверки лечения. Аптечка лечит до 35 здоровья и не расходуется при полном здоровье/после гибели. Сильное падение: при посадке быстрее 10 м/с снимается 8 здоровья за каждый дополнительный м/с. При гибели R возвращает в текущий вагон и восстанавливает здоровье; это временный respawn без выпадения вещей.

## Сохранения
F5 сохраняет ручной слот. F9 читает его, а если ручного слота и его резервной копии нет — автосохранение. В меню можно отдельно загрузить автосохранение. Автосохранение выполняется каждые 120 игровых секунд и после отправления на следующую станцию, пока игрок жив. По умолчанию сохранение не загружается автоматически при Play.

Сохраняются:
- положение/скорость/тормоз/номер остановки поезда, топливо и состояние;
- положение, направление взгляда, здоровье игрока, время суток и фонарик;
- детали, ткань, аптечки, владение оружием, выбранное оружие, магазин и резерв;
- собранные предметы, обысканные ящики, доски, здоровье и положение врагов.

Пули, текущий взмах, стадия перезарядки и промежуточный путь агента не сохраняются; после загрузки они сбрасываются. Положение пассажира сохраняется относительно поезда. Вода, еда, ремнаборы, сытость и вода организма сохраняются с новой схемой. Открытое полотно — временный интерфейс: при загрузке оно закрывается. Короткий и длинный маршруты имеют отдельные профили. Изменение параметров маршрута или набора PersistentEntity может сделать прежние сохранения несовместимыми; поддержана миграция стандартного состава объектов 0.6 → 0.7; прочие несовместимые изменения отклоняются.

Файлы находятся в `Application.persistentDataPath`:
- `save_<профиль>.json` — ручной слот;
- `autosave_<профиль>.json` — автоматический;
- `.bak` — предыдущее состояние соответствующего файла;
- `settings_v1.json` — настройки.

Запись идет во временный файл с последующей заменой, предыдущий файл сохраняется в .bak. SHA-256 проверяет целостность payload; схема, маршрут, числа и ID объектов проверяются до изменения сцены. Если основной файл поврежден, читается резервная копия. При исключении во время применения состояния выполняется попытка отката текущей сцены; ее нужно проверить в Unity.

«Начать маршрут заново» сбрасывает текущую сессию, но не удаляет сохраненные файлы. Не переименовывайте ID объектов вручную, если нужна совместимость с прежним слотом.

## Настройки и локализация
Esc открывает меню: RU/EN, три пресета, текстуры, разрешение и дальность теней, дистанция прорисовки, render scale, MSAA, постобработка, V-Sync, FPS-лимит, счетчик FPS, чувствительность мыши, режим экрана и разрешение. «Применить и сохранить» записывает настройки. В Editor изменение разрешения экрана не применяется автоматически при входе в Play; standalone применяет сохраненный режим.

Меню читает JSON-словари из Resources/Localization. Подсказки прежних модулей пока используют общий языковой флаг и пары RU/EN в коде. Это мгновенное переключение текущего интерфейса, но еще не полная интеграция Unity Localization, локализованного аудио и шрифтов.

Дальность камеры ограничена 300 м с учетом текущего окна чанков. При V-Sync лимит Application.targetFrameRate не определяет фактическую частоту кадров. Preset меняет бюджет качества, но не гарантирует FPS на конкретном ПК.

## Проверки
Выполненные проверки и ограничения перечислены в TEST_REPORT.md. Коротко: 36 проверок независимого C#/.NET-ядра реально выполнены; экспорт/повторный импорт моделей и скелета проверены в Blender; все C#-исходники разобраны синтаксически.

**Unity отсутствует в среде разработки. Проект не скомпилирован и не запущен в Unity. EditMode/PlayMode-тесты, создание NavMesh, поведение AI, звук, меню и реальная производительность в Unity еще не проверены.**

Для независимого ядра нужен .NET 8:

    dotnet run --project Tools/CoreChecks/CoreChecks.csproj

В Unity: Window → General → Test Runner → EditMode / PlayMode → Run All. После этого проверить сцену и Development Build на целевом ПК.

## Обязательная проверка игровой сцены
1. Console без ошибок после импорта и генерации. Пистолет и патроны у верстака, по два врага у каждой станции.
2. Переключение 1/2 не дает одновременно атаковать двумя видами оружия. Магазин/резерв расходуются корректно, перезарядка не создает патроны.
3. Стена блокирует пулю и удар топором. NavMeshAgent следует маршруту, не проходит через закрытые доски; после разрушения проход открывается.
4. Враг реагирует на шум и фонарик, не наносит урон через стены и не атакует погибшего игрока.
5. Esc останавливает поезд, пули, агентов и время; меню не двигает камеру. Настройки восстанавливаются после перезапуска standalone.
6. F5 → изменить лут/здоровье/позицию → F9: восстановление без повторной выдачи припасов. Проверить пассажира и игрока на земле.
7. Сохранить дважды, испортить основной файл, проверить загрузку .bak. Несовместимый/поврежденный слот не должен частично менять сцену.
8. Открыть рюкзак на земле и в движущемся вагоне: полотно не должно толкать игрока, переход камеры/курсор должны восстанавливаться. Проверить предметы и крафт мышью, расход ресурсов, сытость и воду.
9. Esc поверх открытого рюкзака → продолжить: курсор остается свободным до Tab. Проверить смерть/загрузку с открытым полотном.
10. Загрузить сохранение 0.6: прежний лут остается обысканным, новые припасы доступны, показатели и предметы затем сохраняются в 0.7.
11. Пройти четыре станции, проверить износ, ремонт, финальную остановку и постоянное число семи участков. Профилировать CPU/GPU, GC и пики при прогреве/загрузке.

## Что еще не готово
Это остается техническим прототипом. Нет фотореалистичных PBR-текстур, финальной растительности с LOD, объемных лучей, полноценного звездного неба/луны, рук игрока и финальных анимаций. У рюкзака пока фиксированные слоты, нет перетаскивания и анимации рук. Крафт ограничен двумя рецептами; нет разнообразного оружия/врагов, сюжетных задач, таймера отправления, полноценного стартового меню, additive загрузки станций и смещения начала координат. Четыре станции остаются в сцене, деревья — примитивы, колеса вагона не анимированы. Оптимизация до целевого FPS и художественная доработка требуют следующих этапов и реального профилирования.
