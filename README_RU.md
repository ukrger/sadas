# Летний маршрут — технический прототип 0.2

Исходники для **Unity 2022.3 LTS / URP 14**, не готовая Windows-игра.

## Установка и обновление
1. Создайте проект 3D (URP) в Unity 2022.3 LTS.
2. Установите Input System через Package Manager. В Player → Active Input Handling выберите Input System Package (New) либо Both и перезапустите редактор по запросу.
3. Скопируйте содержимое Assets из пакета в Assets своего проекта. При обновлении замените одноименные исходники.
4. Дождитесь импорта SummerRailcar.fbx и компиляции.
5. Выберите **Train Summer → Create Prototype Scene**. Генератор предложит сохранить открытую сцену; затем пересоздаст Generated/Prototype.unity. Перед этим сохраните ручные изменения сцены в другом файле.
6. Нажмите Play.

URP Asset проекта не меняется. Подключение вагона происходит при создании сцены: уже сохраненная сцена версии 0.1 сама не обновится.

## Управление и маршрут
WASD — ходьба, мышь — обзор, Space — прыжок, Esc — захват/освобождение курсора, E — канистра или управление у переднего пульта. F1 — RU/EN, F2 — FPS. Esc не ставит мир на паузу.
Поезд трогается автоматически и останавливается примерно через 25 секунд на отметке 160 м. Выйдите через задний проем справа по ступеням. На платформе возьмите оранжевую канистру (подойти, навести камеру, E). Вернитесь к переднему пульту, нажмите E для отправления. Следующих станций пока нет.

## Новое в 0.2
- SummerRailcar.fbx: корпус с открытыми окнами, крыша, две колесные тележки, оси, ступени, поручни, сцепки, сиденья и пульт с приборами.
- Три LOD: 11 692 / 1 756 / 1 152 треугольника; 6 / 6 / 4 меша соответственно. Материалы объединены внутри каждого LOD.
- RailcarSetup подключает FBX, создает URP-материалы, LODGroup и простые BoxCollider отдельно от визуальных мешей. Ориентация и масштаб выравниваются по семантическим маркерам модели.
- Если FBX отсутствует, остается резервный вариант из примитивов с тем же дверным проемом и интерьерными коллайдерами.
- Контроллер сохраняет горизонтальную скорость платформы при прыжке/сходе; после приземления на землю скорость сбрасывается. При прыжке перенос опорой и унаследованная скорость не складываются дважды.
- Два Blender-рендера: внешний вид и разрез интерьера. Это изображения модели, не скриншоты Unity.

## Генерация модели
Внимание: генератор очищает текущую сцену Blender. Запускайте в background или в отдельном файле.

    blender -b --python Tools/Blender/generate_train_car.py -- --project /путь/к/UnityProject --render

Без --render создаются FBX, статистика и исходный .blend. Рендеры при --render сохраняются в Previews. Исходник хранится в Tools/Blender/Source, вне Assets: Unity не будет требовать Blender для импорта .blend. Модель сохраняется до создания студии и до разреза для интерьерного изображения; FBX остается целым.

    blender -b --python Tools/Blender/validate_train_car.py -- --project /путь/к/UnityProject

Валидатор проверяет повторный импорт FBX, три LOD, 16 мешей, масштаб маркеров, габариты и свободный дверной проем на трех высотах.

## Выполненные проверки
- Blender 4.3.2: генерация и FBX-экспорт; повторный импорт и проверки валидатора пройдены.
- 8 C#-файлов: синтаксический разбор tree-sitter C# без ошибок. Это не компиляция и не проверка Unity API.
- Отдельный расчет торможения при 20/30/60/144 FPS: остановка на 160 м.
- Unity в среде создания отсутствует. Компиляция, физика, переходы между опорами и FPS не проверены в Unity.

## Проверить в Unity перед использованием
- Console без ошибок; после генерации видно один LOD, материалы отображаются корректно.
- Дверь справа сзади, ступени совпадают с визуальной моделью, окна открыты.
- Игрок ходит по вагону без отставания, прыгает внутри движущегося вагона и возвращается на пол.
- При прыжке с поезда сохраняется начальная продольная скорость; после приземления на землю игрок не скользит.
- Канистра собирается один раз; отправление у пульта работает после возвращения.
- В standalone Development Build проверьте Frame Debugger, переключение LOD и CPU/GPU Profiler.

## Остающиеся ограничения
Это художественный блокинг с базовыми материалами: нет PBR-текстур, старения, полноценной UV-подготовки, прозрачных стекол и анимации колес. До фотореализма необходим отдельный этап технической и художественной доработки.
Маршрут прямой, начало координат не смещается. Стример синхронно создает/удаляет примитивы; pooling и additive loading пока отсутствуют. Деревья не имеют LOD. Нет сохранений, врагов, оружия, крафта, физического рюкзака и полноценного меню. RU/EN — временные строки интерфейса, а не Unity Localization. Ночное освещение упрощено.
