# Train Summer — технический прототип 0.9

Unity **2022.3 LTS / URP 14 Forward**, Input System. Это пакет исходников, самостоятельно созданных моделей и процедурных текстур, **не проверенная готовая игра или EXE**. В этой среде нет Unity: доступные независимые проверки выполнены, запуск движка и измерение FPS остаются обязательными.

## Запуск
1. Создайте проект **3D (URP)** в Unity 2022.3 LTS. Установите Input System, включите Player → Active Input Handling → Input System Package (New) либо Both и перезапустите редактор по запросу.
2. Скопируйте `Assets` из пакета в проект. Дождитесь импорта и компиляции. Для тестов установите Unity Test Framework.
3. Выберите **Train Summer → Create Prototype Scene** для короткой проверки либо **Create Long Route Scene** для маршрута с интервалами поездки примерно 6–7 минут между станциями.
4. Нажмите Play. Откроется стартовое меню: начать маршрут, загрузить ручной слот/автосохранение, настройки.
5. После обновления с любой прежней версии **обязательно пересоздайте сцену**. Сохраните ручные изменения отдельно: Generated/Prototype.unity и Prototype_Long.unity перезаписываются.

Содержимое Generated принадлежит генератору. Не храните там единственные экземпляры ручной работы. Исходный URP Asset проекта генератор не изменяет: создаются свои профили теней и Forward renderer assets. Во время игры активируется временная копия профиля; при выходе прежние ссылки и параметры качества восстанавливаются. Генератор ожидает обычный Universal Renderer, не 2D Renderer.

Для навигации используется встроенный UnityEngine.AI/NavMeshBuilder. AI Navigation отдельно не нужен. Blender требуется только для повторной генерации ассетов; готовые FBX импортируются без Blender.

## Новое в 0.9
- Стартовый экран, отдельные настройки, пауза, загрузка, экраны смерти и завершения маршрута. Смерть завершает текущую попытку: загрузите слот или начните заново; прежний бесплатный respawn по R удалён. Техническая страховка при падении за нижнюю границу мира остаётся.
- Цель маршрута: **забрать радиомодуль из рации в каждом из четырёх станционных домов и доехать до конца пути**. Чужой или уже собранный модуль не дублируется. Отправиться с плановой станции без её модуля нельзя.
- На станции начинается ожидание 180 игровых секунд. После истечения таймера поезд отправляется, если модуль забран, игрок на борту, есть топливо и состав исправен. Иначе ожидает выполнения этих условий. У пульта можно отправиться раньше. В настройках можно отключить автоотправление; режим входит в сохранение сессии.
- Три вида огнестрельного оружия: пистолет, дробовик и автомат. Дробовик: магазин-трубка на 5, поштучная зарядка, 8 дробин на выстрел. Автомат: магазин 30, огонь удержанием ЛКМ. Боезапас каждого вида отдельный, зарядка сохраняет общее количество патронов. Пули/дробь летят с гравитацией и проверкой столкновений по отрезку.
- **Прицеливание по удержанию ПКМ** для всех трёх видов. Положение оружия решается по `Aim Reference`: точка целика и её направление совмещаются с центром камеры на расстоянии 23 см. Переход сглажен; FOV 75 → 58, чувствительность до 50%, ходьба до 70%. Меньше разброс и покачивание, экранный крестик скрывается. Смена оружия, рюкзак, смерть, пауза и загрузка сбрасывают прицел; перезарядка плавно выводит из него. Отдача изменяет настоящий pitch/yaw взгляда. Это механические прицельные приспособления, без оптического прицела и системы пристрелки.
- Первая канистра обновлена до общего FBX/LOD-конвейера и заменяет кубик топлива в станционном доме, с сохранением прежнего ID.
- Шесть новых моделей, **двумя тройками**: PumpShotgun, PlayerHands, FieldRadio; AutomaticRifle, StationZombie, RailSignal. Руки в перчатках следуют оружейным pivot: это статическая геометрия, не skinned-анимация пальцев и не полноценная анимация зарядки. У зомби отдельный generic-скелет и Idle/Walk. Он медленнее мутанта; общий AI реагирует на видимость, шум и фонарик. Имена сохраняемых врагов сохранены для совместимости.
- Сигналы на станциях меняют красный/зелёный по факту получения радиомодуля. Это индикатор задачи, не полноценная железнодорожная блокировка и не гарантия готовности поезда к отправлению.
- Свой shader неба: ясный день, редкие светлые облака, тёплый горизонт, солнечный диск, луна и звёзды. Ночью отдельный холодный Directional Light без теней. Это художественная аппроксимация, не астрономическая симуляция.
- URP SunShaftFeature: экранные лучи по маске глубины, половинное разрешение маски/размытия, 16 радиальных выборок. Работает только в основной игровой камере при включённой постобработке и видимом дневном солнце. **Это не объёмный туман**. В Low постобработка и эффект отключены. Реальная стоимость и артефакты ещё не профилированы.
- **21 собственная PBR-карта**: albedo, tangent normal и metallic/smoothness для 7 типов поверхности. Одинаковый production C# SurfacePattern используется offline-экспортом и Unity Editor baker. SurfaceBaker подключает карты к материалам дерева, стали, краски, ткани, кожи, штукатурки и кирпича. Это базовые процедурные материалы, не финальные фотосканированные текстуры. Листва и кожа персонажей не получают эти карты автоматически.
- Синтезированный фоновый звук поезда и летнего воздуха без чужих аудиофайлов. Это временный звук, не финальный саунд-дизайн.
- Дальние станции отключают Renderers/Collider/AI/NavMesh через активацию корневого объекта. Они остаются в памяти: **это не additive scene streaming и не выгрузка ассетов**. Окно защищает и поезд, и пешего игрока, с гистерезисом 420/500 м. Состояние дочерних предметов сохраняется независимо от активации станции.
- Команды проверки сцены, Windows Development Build и bake occlusion для неподвижной геометрии станций. Подробнее: Docs/BUILD_AND_TEST_RU.md.

## Управление
| Клавиша | Действие |
|---|---|
| WASD / мышь / Space | Ходьба / взгляд / прыжок |
| E | Подбор, осмотр, модуль из рации; у переднего пульта — тормоз / отправление |
| Tab | Открыть / закрыть физическое 3D-полотно рюкзака |
| ЛКМ / ПКМ | Атака / удерживать для прицеливания |
| 1 / 2 / 3 / 4 | Топор / пистолет / дробовик / автомат; повторное нажатие убирает |
| R / F / H | Перезарядка / фонарик / аптечка |
| Esc | Пауза / возврат из настроек |
| F5 / F9 | Ручное сохранение / загрузка |
| F1 / F2 / F3 / F4 | RU–EN / FPS / помощь / статистика окружения |

Оружие и припасы находятся в вагоне; автомат закреплён возле левой стены за сиденьями, остальное — у верстака. На станциях есть канистры, ящики, еда/вода, аптечки, патроны и рация. Доски входа разбиваются топором. Подбирать предметы нужно наведением и E.

Показатели сытости и воды уменьшаются в игровом времени. Вода +45, еда +35, аптечка до +35 здоровья; расход предмета блокируется при полном показателе. Крафт: ремнабор = 3 детали + 1 ткань, аптечка = 1 деталь + 2 ткани. Ремонт только при остановке; ремнабор внутри поезда даёт до +25 состояния. Старый ремонт на верстаке из деталей/ткани тоже сохранён. При полном выходном стеке ингредиенты не тратятся.

## Рюкзак и HUD
Камера опускается к отдельной 3D-поверхности с моделями предметов. Полотно рисуется камерой Overlay на слое 9, не сталкивается с игроком и не попадает в лесной instancing. Клик выбирает оружие или использует припас. Для количества показывается один предмет со счётчиком. Это фиксированная раскладка, без перетаскивания и анимации рук. Мир продолжает двигаться. На поезде перенос опорой продолжается даже при открытом рюкзаке.

HUD показывает здоровье, при нахождении на борту — скорость/топливо/дистанцию, боезапас выбранного оружия, количество модулей. Низкие потребности появляются автоматически, подробности — F3. F4 — технические счётчики: участки, видимые растения и API-подачи мешей; это не полные GPU draw calls.

## Сохранения и обновление
Схема 3: поезд/топливо/ремонт, игрок/взгляд/здоровье/фонарь, время, потребности, весь инвентарь, выбранное оружие/магазины/резервы, состояние лута/досок/врагов, маска радиомодулей, таймер и режим отправления. Пули, стадия перезарядки, промежуточный путь AI, открытое полотно и состояние прицеливания не сохраняются: после загрузки сбрасываются.

Поддержана миграция стандартных сохранений 0.6–0.8: старый лут и показатели сохраняются, новые оружейные pickup получают исходное состояние. Модули уже покинутых станций засчитываются, поскольку поезд не возвращается назад. На текущей станции старого слота начинается полное ожидание 180 секунд. Новое оружие остаётся доступным для подбора. Вручную изменённые маршруты/ID и неизвестные отсутствующие старые объекты отклоняются.

Файлы — Application.persistentDataPath: save_<профиль>.json, autosave_<профиль>.json, их .bak, settings_v1.json. Короткий и длинный маршрут имеют разные профили. Запись через временный файл/замену, предыдущий слот сохраняется в .bak; SHA-256 проверяет payload. Проверка данных выполняется до изменения сцены; если восстановление сцены вызывает исключение — попытка отката. Интеграцию JsonUtility/Unity-сцены ещё нужно прогнать в движке.

Автосохранение — каждые 120 игровых секунд, после отправления и при завершении маршрута. F9 сначала ищет ручной слот, при отсутствии — автоматический; повреждённый слот пробует .bak. «Начать заново» сбрасывает сессию, но не удаляет файлы. Режим автоотправления сохраняется в слоте; остальные графические настройки — отдельным файлом.

## Графика и окружение
См. **Docs/URP_SETUP_RU.md**. Сохранены пул из 10 участков маршрута, GPU instancing берёз/сосен/травы, CPU frustum/distance LOD, общий ветер в проходах цвета/тени/глубины, объединённые рельсы/шпалы и mesh collider. Семь участков возле состава плюс до трёх у отставшего игрока. Реальная эффективность ещё не установлена измерением.

В руинах вне станций пока нет интерактивного лута. Деревья, трава и руины детерминированы. Первое построение NavMesh, прогрев пула и приготовление MeshCollider синхронные: возможны пики CPU. Scene View может не показывать программный лес так же, как игровая камера. LOD растительности без кроссфейда. Дальность камеры до 300 м. Стволы/руины не включаются динамически в станционный NavMesh.

Для standalone: Graphics → Shader Stripping → Instancing Variants → **Keep All**, затем оптимизировать варианты по результатам Frame Debugger. Слои 8 (враги), 9 (полотно) и 2 (игрок) зарезервированы генератором. Гибкие пресеты, MSAA, render scale, экран/разрешение, V-Sync, FPS-лимит, текстуры, тени, дистанции, постобработка и RU/EN доступны в меню. Локализация: JSON словари меню + пары RU/EN некоторых игровых подсказок. Нет локализованной озвучки и полной Unity Localization-интеграции.

## Модели и Blender
Все FBX находятся в Assets/Models, источники — Tools/Blender/Source, генераторы — Tools/Blender. Превью — Previews. Включены все прежние модели и новая шестёрка; у моделей три LOD. Модель рук статическая; зомби и мутант используют rigid-segment skinning и простые Idle/Walk.

    blender -b --python Tools/Blender/generate_pump_shotgun.py -- --project /UnityProject --render
    blender -b --python Tools/Blender/generate_player_hands.py -- --project /UnityProject --render
    blender -b --python Tools/Blender/generate_field_radio.py -- --project /UnityProject --render
    blender -b --python Tools/Blender/generate_automatic_rifle.py -- --project /UnityProject --render
    blender -b --python Tools/Blender/generate_zombie.py -- --project /UnityProject --render
    blender -b --python Tools/Blender/generate_rail_signal.py -- --project /UnityProject --render
    blender -b --python Tools/Blender/validate_journey_models.py -- --project /UnityProject
    blender -b --python Tools/Blender/validate_combat_models.py -- --project /UnityProject
    blender -b --python Tools/Blender/render_aiming.py -- --project /UnityProject

Генераторы очищают открытую сцену Blender: запускайте background или отдельный файл. Общие prop_pipeline.py/environment_pipeline.py должны лежать рядом. Фотографии моделей и прицеливания — реальные Blender-рендеры экспортированных ассетов, **не скриншоты Unity и не доказательство работы игровых систем**.
